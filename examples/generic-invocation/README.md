# Dubbo-Go Generic Invocation Examples

这个目录包含了Dubbo-Go泛化调用的示例代码，展示了如何在不依赖具体服务接口的情况下动态调用Dubbo服务。

## 示例说明

### basic_demo.go - 基础泛化调用示例

这个示例展示了最基本的泛化调用用法：

1. **服务端启动**: 启动一个简单的数学计算服务
2. **客户端调用**: 使用泛化调用动态调用服务端的方法
3. **功能演示**:
   - 加法运算
   - 乘法运算
   - 错误处理

**运行方式**:
```bash
go run basic_demo.go
```

### gateway_demo.go - 网关模式泛化调用示例

这个示例展示了在网关场景下使用泛化调用的高级用法：

1. **多服务调用**: 同时调用用户服务、订单服务和通知服务
2. **并发处理**: 使用goroutine并发处理多个业务请求
3. **错误处理**: 完善的错误处理和恢复机制
4. **业务流程**: 模拟完整的业务流程处理

**运行方式**:
```bash
go run gateway_demo.go
```

## 泛化调用的优势

1. **动态调用**: 无需预先知道服务接口定义
2. **服务治理**: 支持负载均衡、熔断、限流等服务治理功能
3. **灵活性**: 适合网关、API聚合等场景
4. **版本兼容**: 对服务接口变更有更好的兼容性

## 使用场景

1. **API网关**: 动态路由和聚合多个微服务
2. **服务网格**: 运行时的服务发现和调用
3. **业务流程编排**: 动态组合多个服务调用
4. **测试工具**: 自动化测试和压力测试

## 注意事项

1. 泛化调用相比普通调用有一定的性能开销
2. 参数类型需要精确匹配服务端的接口定义
3. 异常处理需要考虑更多边界情况
4. 建议在网关和工具类应用中使用
